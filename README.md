# Community Chord

Community Chord is a no-build social music community prototype. It helps musicians discover bandmates, join genre communities, find local events, and share collaboration ideas.

## Run locally

Open `index.html` in a modern browser. The prototype uses only local HTML, CSS, and JavaScript; it does not require a server, account, database, external framework, or install step.

## Project files

- `index.html` contains the page structure and content sections.
- `styles.css` contains the dark responsive visual design.
- `data.js` contains fictional profiles, communities, events, and starter ideas.
- `app.js` implements search, filters, matching, connections, joins, RSVPs, and idea sharing.

Interactive state is held in the browser page only and resets when the page is reloaded.
